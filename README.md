Projeto API
API é nada mais que nada menos um conjunto de elementos que permite que diferentes sistemas conversem entre si. Além de permitir operações , leitura, atualização e remoção de dados através de requisições HTTP.

Objetivo do Projeto
- Entender o funcionamento de APIs REST
- Como organizar as rotas
- Melhorar o conhecimento sobre BACK-END
- Trabalhar com funcionamentos HTTP

Ferramentas utilizadas
- Index.html
- Style.css
- Java.Script
- Package.json
- MockAPI

Estrutura da API
A API ela é constituída por rotas onde elas definem qual ação será executada. Exemplo GET/ USUÁRIO ou seja o GET ele busca informações e o usuário é o endpoint desta API. Após, vem os controllers, que por sua vez recebem as requisições e definem o que será executado como buscar um usuário, cadastrar dentre outros. Uma parte fundamental que não pode faltar é o banco de dados, pois ele armazena as informações desta aplicação. E aqui está alguns exemplos de bancos mais utilizados tais como MySQL, PostgreSQL dentre outros. Após entra o JSON (JavaScript Object Notation) ele que recebe e envia esses dados. Então vem a autenticação por sua vez faz a proteção de dados como Senhas, Logins Tokens etc. Resumidamente a API passa por essas funções para que tudo seja executado com sucesso!.


Funcionamento do Sistema
O projeto foi desenvolvido em parceria com uma enfermeira, visando facilitar o controle dos materiais utilizados no almoxarifado.

O sistema permite que o usuário:
Pesquise materiais, como luvas, seringas e outros itens hospitalares;
Informe a quantidade disponível de cada material;
Visualize o histórico de movimentações;
Consulte materiais com estoque negativo ou insuficiente;
Tenha um controle mais organizado dos itens armazenados.
Dessa forma, o gerenciamento do estoque torna-se mais simples, rápido e eficiente para o dia a dia da enfermagem.
